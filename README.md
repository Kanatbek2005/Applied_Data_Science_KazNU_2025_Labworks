# Қолданбалы деректер ғылымы ҚазҰУ 2025 Зертханалық Жұмыстар

## Applied Data Science, KazNU, Spring 2025 зертханалық жұмыстар мен деректер материалдарының жинағы.

Бұл репозиторий ҚазҰУ-дың 2025 жылғы көктемгі семестріндегі «Қолданбалы деректер ғылымы» пәніне арналған зертханалық жұмыстар мен деректер бойынша мәліметтер қамтылған.

## Құрылымы

Репозиторийдің құрылымы келесідей:

- Әр аптаға бөлек қалта.
- Әр аптада: Jupyter ноутбук және оған жаңа dataset қалтасы бар.

## Деректер мен модельдер

- **Деректер**: [Kaz_traffic_data_week12](https://huggingface.co/datasets/Kanatbek05/kaz_traffic_data_week12/tree/main)
- **Модель**: [Kaz_Roberta_fine_tuned](https://huggingface.co/Kanatbek05/Kaz_Roberta_fine_tuned/tree/main)
